# Security Policy

## Reporting Security Issues

The Eraser maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/eraser-dev/eraser/security/advisories/new) form.

For more details, see the [Eraser security policy](https://github.com/eraser-dev/eraser/blob/main/SECURITY.md).
